v2.0.0

World of Warcraft Retro Launcher v2.0.0 is a ground-up rebuild of the software. This version of the project will be more reliable, customisable, generally look better and last but not least, be more authentic to the original WoW launchers.
Underneath, you will find a full list of changes from the last project.


Updated graphics
- Updated graphics taken from the original software includes the button textures, button-text fonts and the news parchment background.
- New 'news' icons based on the icons that used to be present in the WoW forums. These will be able to switched out for the original icons in a future update.
- New 'news' title graphics, redone to more closely resemble those of the original launcher.
- New WoW based UI element graphics, like dropdowns, checkboxes and buttons.

Sounds
- New 'PLAY' sound, as it turned out the sound I used in the original project was actually wrong. Oops!
- New interface sounds, based on those from the original WoW installers. These can be toggled off in the settings.

Backgrounds (Splashes)
- Backgrounds (renamed Splashes) will contain both a background and a foreground. This is in tune with the original WoW launchers, and gives more depth to the software.
- Note: With this change, all backgrounds have been removed, and new ones will be added in future updates.
Settings
- New settings screen. This settings screen resembles that of the in-game game menu. Here you will be able to tune a number of settings in the launcher.
- These settings include toggling automatic update checks, toggling connection warnings, toggling sounds and more.
- In the future, many more settings will be added for you to customize your experience.


Important to note, that with this ground-up revamp of the project, for now, it only has the look of the original Vanilla launcher. Future updates will include other expansion packs, more backgrounds, more settings and more. Stay tuned!
